---
title: What is Zylos
description: A self-hosted AI companion that persists, remembers, and acts autonomously.
---

Zylos is a framework that turns Claude into a persistent, self-hosted AI companion. Unlike a typical chatbot that forgets you the moment you close the window, Zylos maintains long-term memory, operates across multiple communication channels, and can take autonomous action on your behalf.

## How Zylos Differs from ChatGPT or Claude Web

| Feature | Chat interfaces | Zylos |
|---|---|---|
| **Memory** | Resets each conversation | Persistent across sessions, tiered memory system |
| **Availability** | Only when you open the app | Always running on your server |
| **Channels** | Single web interface | Telegram, Lark, web console, and more |
| **Autonomy** | Responds only when prompted | Can schedule tasks and act independently |
| **Customization** | Limited system prompts | Full control over behavior, skills, and integrations |
| **Data ownership** | Stored on provider servers | Everything stays on your machine |

## Key Capabilities

### Persistent Memory

Zylos maintains a structured memory system inspired by cognitive science. It remembers your preferences, ongoing projects, past decisions, and important context -- then uses that knowledge to give better, more personalized responses over time.

### Multi-Channel Communication

Connect Zylos to the platforms you already use. Send it a message on Telegram, get a response in your web console, or let it post updates to a group chat. All channels feed into the same persistent context.

### Modular Components

Zylos is built from composable components -- activity monitoring, communication bridges, schedulers, HTTP services, and more. Install only what you need, or build custom skills to extend its capabilities.

### Self-Monitoring

Zylos watches its own health. If a service goes down, it knows. If something needs attention, it can alert you or attempt to fix it autonomously.

### Task Scheduling

Set up recurring tasks, deferred follow-ups, or time-triggered actions. Zylos can wake itself up at the right moment without waiting for your input.

## What You Can Do With It

- **Daily briefings**: Get a morning summary of your calendar, tasks, and anything Zylos noticed overnight
- **Task automation**: "Remind me to check on the deployment in 2 hours" -- and it actually will
- **Team assistant**: Add Zylos to a group chat where it helps answer questions, track decisions, and maintain shared context
- **Research companion**: Ask it to investigate a topic and report back with findings
- **Personal knowledge base**: Zylos remembers what you tell it, so you don't have to repeat yourself

## A Companion That Grows With You

Zylos is a companion that grows with you -- learning your preferences, understanding your projects, and becoming more useful the longer you use it. Think of it less as a tool and more as a digital colleague that never sleeps.
