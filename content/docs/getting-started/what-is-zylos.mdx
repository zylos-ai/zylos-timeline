Zylos is a self-hosted AI companion framework with persistent memory, multi-channel communication, and autonomous capabilities — built for individuals and teams.

## Key Capabilities

- **Persistent Memory** -- Structured, tiered memory system that retains your preferences, projects, and context across sessions.
- **Multi-Channel** -- Connect Telegram, Lark, Slack, WhatsApp, web console, and more. All channels share the same context.
- **Autonomous Scheduling** -- Set tasks, reminders, and recurring actions. Zylos wakes itself up at the right time.
- **Self-Monitoring** -- Detects service failures and can self-heal or alert you.
- **Modular Components** -- Install only what you need. Build custom skills for anything else.

## What You Can Do With It

- Get a morning briefing of your calendar, tasks, and anything Zylos noticed overnight
- Say "remind me to check the deployment in 2 hours" -- and it will
- Add Zylos to a group chat to answer questions, track decisions, and maintain shared context
- Ask it to research a topic and report back with findings
- Tell it something once and never repeat yourself -- it remembers
