Before installing Zylos, make sure your environment meets the requirements below and that you have the necessary accounts ready.

## System Requirements

| Requirement | Minimum | Recommended |
|---|---|---|
| **Operating System** | Ubuntu 22.04+ or Debian 12+ | Ubuntu 24.04 LTS |
| **CPU** | 2 cores | 4+ cores |
| **RAM** | 4 GB | 8+ GB |
| **Disk** | 20 GB | 50+ GB SSD |
| **Node.js** | 20.20+ | Latest LTS |

Zylos runs on Linux. macOS works for development but is not recommended for production. Windows is not supported (use WSL2 if needed).

## Required Accounts

### Anthropic API Access

Zylos is powered by Claude. You need one of the following:

- **Anthropic API key** -- Pay-per-use via the [Anthropic Console](https://console.anthropic.com). Best for variable usage patterns.
- **Claude Max subscription** -- Flat monthly rate with generous limits. Best for heavy, consistent usage.

### GitHub (Optional)

A GitHub account is helpful for:
- Accessing Zylos source code and updates
- Reporting issues and contributing
- Using GitHub-based integrations

## Optional Services

These are not required for a basic setup but unlock additional capabilities:

- **Domain name** -- Needed if you want HTTPS access to the web console from outside your network
- **Telegram account** -- For the Telegram communication channel
- **Lark/Feishu account** -- For the Lark communication channel

## Estimated Costs

| Item | Cost |
|---|---|
| **Cloud server** | $5--20/month (Hetzner, DigitalOcean, etc.) |
| **Anthropic API** | Variable -- depends on usage. Light use ~$5--15/month |
| **Claude Max** | Fixed monthly subscription (check current pricing) |
| **Domain name** | ~$10--15/year (optional) |

You can run Zylos on any machine you control -- a cloud VPS or a spare laptop. The only ongoing cost is the AI model access.

## What You'll Need Ready

Before starting the installation:

1. **Terminal access** to your server (SSH or direct)
2. **Node.js 20.20+** installed (`node --version` to check)
3. **Your Anthropic API key** or Claude Max credentials
4. **15--20 minutes** of uninterrupted time

Once you have everything above, you're ready to [install Zylos](/docs/getting-started/installation).
