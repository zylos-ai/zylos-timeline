## Fixing Problems

**Talk to Zylos first.** Describe what's wrong in any connected channel or `zylos shell` — Zylos can diagnose, restart services, and fix configuration on its own.

If Zylos is unreachable, run `zylos doctor` from the command line for automated diagnostics and repair.

## Reliability

Zylos self-heals. The activity monitor auto-restarts the agent after crashes, rotates sessions when context gets high, and runs periodic liveness checks. No configuration needed.
