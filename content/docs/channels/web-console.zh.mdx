Web 控制台是与 Zylos 通信的内置浏览器界面，无需任何外部账号或平台配置——打开 URL 即可开始聊天。

**预计配置时间：** 已随 Zylos 核心内置，无需额外配置

## 工作原理

Web 控制台是一个轻量级 Web 聊天界面，在端口 `3456` 上运行独立 HTTP 服务。Caddy（反向代理）将其暴露在你的域名的 `/console` 路径下（端口 80/443），用户通过 `https://your-domain.com/console` 访问。消息与其他渠道一样，流经同一个 C4 通信桥。

## 访问控制台

如果你在安装时配置了域名：

```
https://your-domain.com/console
```

本地访问（绕过 Caddy）：

```
http://localhost:3456
```

## 身份验证

Web 控制台使用密码认证。Zylos 安装完成后会自动生成并显示密码。

稍后如需找回密码：
- **通过 Shell：** 运行 `zylos shell`，然后问"我的 Web 控制台密码是什么？"
- **通过其他渠道：** 在 Telegram、Lark 或任意已连接的 IM 中询问 Zylos

手动修改密码，编辑 `~/zylos/.env`：

```bash
WEB_CONSOLE_PASSWORD=your-new-password
```

然后重启服务：

```bash
pm2 restart web-console
```

## 功能

- **实时消息** -- 在浏览器中收发消息
- **Markdown 渲染** -- 回复支持完整的 Markdown 格式
- **文件分享** -- 通过聊天界面共享文件
- **移动端友好** -- 在手机和平板上同样可用
- **零安装** -- 只需一个 URL，任何设备的浏览器均可访问

## 适用场景

Web 控制台特别适合：
- **快速访问** -- 从任何设备访问，无需安装 App
- **初始配置** -- 在配置 Telegram 或 Lark 之前使用
- **共享访问** -- 提供 URL 和密码，给他人临时使用权限
- **开发调试** -- 无需切换到消息应用即可测试交互

## 配置参考

| 配置项 | 位置 | 说明 |
|---------|----------|-------------|
| `WEB_CONSOLE_PASSWORD` | `~/zylos/.env` | 认证密码 |
| PM2 服务 | `web-console` | PM2 命令中使用的服务名称 |
| 默认端口 | `3456` | HTTP 端口（通过 Caddy 在 `/console` 路径代理） |
