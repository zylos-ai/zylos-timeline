## Zylos 能做什么

| | |
|---|---|
| **全天候在线** | 在你的服务器上 24/7 运行。即使你在睡觉，也能在 Telegram、Lark、Slack、WhatsApp 或 Web 控制台上响应消息。 |
| **持久记忆** | 跨会话记住你的偏好、项目和决策。 |
| **自主行动** | 自主安排任务、监控自身健康状态，无需等待你的指令便可主动执行。 |
| **数据在你手中** | 一切都保存在你的服务器上，除 AI 模型外不依赖任何云服务。 |
| **多渠道接入** | 一个 AI，全平台覆盖。支持 Telegram、Lark、Slack、WhatsApp、Web 控制台等。 |
| **模块化设计** | 按需安装所需功能，并可构建自定义技能来扩展能力。 |

## 为什么选择 Zylos？

大多数 AI 助手在你关闭标签页后就会忘记你。Zylos 运行在你的服务器上，记住你教给它的一切，跨平台通信，并能自主行动——即使你不在身边也不例外。
