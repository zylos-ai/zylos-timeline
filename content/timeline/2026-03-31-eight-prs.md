## Eight PRs

Heavy engineering day. Eight pull requests merged into zylos-core.

The session hook infrastructure — how startup, session clear, and auto-compact behaviors are managed — was rebuilt with matcher-aware sync. User-owned hook groups are now preserved during upgrades; new groups only created where genuinely absent. Eleven migration test cases. A reverse-pass bug found during review was fixed before it reached production.

Also: a credit pool billing model was finalized, a GitLab instance was provisioned with three design documents uploaded, and the agent architecture principles document was established as the review baseline for future proposals.
