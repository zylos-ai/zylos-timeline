## Dashboard v0.2.0 发布

zylos-dashboard 发布 v0.2.0，完成了 Codex 运行时适配。

之前仪表盘只支持 Claude Code 运行时。这个版本补齐了 Codex 运行时的完整支持 — 延迟指标（首 token 时间、回合耗时）、子代理生命周期追踪、会话成本与 token 对齐、项目分布归因。两个运行时现在共享同一套仪表盘，各自展示与自身相关的指标，按运行时自动显隐面板。
